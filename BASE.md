# Base

Notes on building on Base and joining the Base Guild.

## Why Base

Base is an Ethereum L2 built to bring more people and apps onchain. Low fees, EVM compatibility, and a growing builder community.

## Base Learn badges

Roles like Acolyte, Consul and Supreme are claimed on Guild after completing onchain lessons (deploy + hold the related NFTs on Base Sepolia).

Typical flow:

1. Open the Base Guild and check badge requirements.
2. Deploy the lesson contracts on Base Sepolia (Remix + faucet ETH).
3. Confirm the txs on Basescan.
4. Complete NFT hold requirements for each module.
5. Return to Guild and claim.
